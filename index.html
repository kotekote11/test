Привязка: 4 мА = 0 % = 0 Гц = DMX 0, 20 мА = 100 % = 50 Гц = DMX 255.
Доля диапазона P = (I−4)/16 = F/50 = DMX/255 = %/100.
Шаг: 1 % = 0,16 мА = 0,5 Гц = 2,55 ед. DMX; 1 шаг DMX = 2,55 % = 0,408 мА = 1,275 Гц.
Значения за пределами диапазона ограничиваются автоматически.
